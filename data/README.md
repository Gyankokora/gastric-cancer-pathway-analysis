# Data sources

This project analysed the following public GEO microarray datasets:

- **GSE19826**: 12 tumour samples and 15 normal/control samples.
- **GSE54129**: 111 tumour samples and 21 normal/control samples.
- **GSE118916**: 15 tumour samples and 15 normal/control samples.

The comparisons were performed using GEO2R, with the common dysregulated genes compared in R. See the project report for the full methods and interpretation.

Raw patient-level data are not redistributed here. Please consult the GEO records for original data and usage information.
